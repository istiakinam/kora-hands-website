KORA WEBSITE
============
Double-click index.html (or right-click > Open with > browser, or "Open with Live Server" in VS Code).
It is a single self-contained file. Internet is needed for the Unsplash images and Google Fonts.

To edit the design:
  1. cd source
  2. npm install
  3. npm run dev            (live preview while editing)
  4. npm run build:static   (creates source/site/index.html)
  5. Copy source/site/index.html over the top-level index.html
